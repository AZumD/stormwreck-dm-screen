# Campaign view theme assets

Static images for the DM campaign screen three-column layout. Served from the repo at `/assets/campaign/*` (works locally and on Railway).

| File | Use |
|------|-----|
| `left-sidebar.png` | Left nav sidebar (`.sidebar`) |
| `main-body.png` | Central scene/content area (`.main-scroll`) |
| `right-sidebar.png` | Map / party rail (`.map-panel`) |

Referenced in `css/style.css` via `--campaign-nav-bg`, `--campaign-main-bg`, and `--campaign-map-bg`.
