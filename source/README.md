# Source material

Place the official booklet PDF here:

- `5e-dragons-of-stormwreck-isle_text.pdf` ✓

The app does not read PDFs automatically. Use it as reference when pasting or editing sections in the campaign view (Edit mode) or in `js/campaigns/stormwreck-isle/adventure.js`.

Edits made in the browser are saved to **localStorage** and override the defaults until you reset a section.
