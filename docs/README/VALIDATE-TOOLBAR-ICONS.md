# VALIDATE-TOOLBAR-ICONS.js

## Purpose
Static checks that the campaign toolbar uses a text **Run | Prep** workspace switcher, a compact **campaign-time** control (no persistent day/time bar), no Edit / Play-Document primary toggles, and that chapter titles are not auto-injected.

## File
`test/validate-toolbar-icons.js`

## Run
```bash
node test/validate-toolbar-icons.js
```
