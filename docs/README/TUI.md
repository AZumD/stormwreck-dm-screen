# TUI (stormwreck)

## Purpose
Native terminal DM tracker client (Go + Bubble Tea). First-class alongside the browser DM and player apps. Server remains canonical.

## Location
`tui/` — binary entry `tui/cmd/stormwreck`

## Docs
Full usage, Pi build, controls, and limitations: `tui/README.md`

Architecture contract: `docs/CLIENT-ARCHITECTURE.md`

Requires Go 1.24+ (Bubble Tea ≥ 1.3.2 for Windows AltGr/`@` keyboard layouts).
