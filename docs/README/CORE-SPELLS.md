# CORE-SPELLS.js

## Purpose
Starter spell catalogue seeds (condensed 5e-style DM reference).

## File
`js/catalogue-seeds/core-spells.js`

## Contents
~70 common spells: cantrips through 9th (staples, not a full SRD dump).

Merges into `window.CatalogueSeeds.spell` without wiping other seed files. Missing IDs only on catalogue open.

`spell-katalog/index.html`
